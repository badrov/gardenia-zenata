## ⚡ Déploiement rapide (< 5 minutes)

### Option 1 — Netlify Drop (le plus simple)
1. Allez sur https://app.netlify.com/drop
2. Glissez-déposez le fichier `index.html`
3. Votre page est en ligne instantanément avec une URL publique

### Option 2 — GitHub Pages (gratuit)
1. Créez un compte GitHub : https://github.com
2. Nouveau repository → uploadez `index.html`
3. Settings → Pages → Source: main → Save
4. URL : https://votre-nom.github.io/nom-repo

### Option 3 — Vercel (le plus rapide)
1. https://vercel.com/new
2. Uploadez le dossier
3. Deploy → URL instantanée
